## Protected-Process Memory Inspector — Kernel-Backed Instrumentation Study

**Measured VM context (synthetic fixture values).** Host: Windows 11 Pro 23H2 (build 22631.3527), x64, running inside the requester-owned diagnostic VM `DIAG-VM-08`. Observed processes: `calc.exe` (PID 6124, accessible synthetic target) and `MsMpEng.exe` (PID 4212, inaccessible protected target, PPL). Synthetic pages were allocated in `calc.exe`'s address space by the fixture harness for measurement. Launch confirmation required by local diagnostics policy: `LaunchConfirmation=Calculator.exe PID=6124 ExitCode=0`.

### Instrumented Observer Implementation (read-only)

The observer requests only `PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ`. No `VM_WRITE`, no `VM_OPERATION`, no `CREATE_THREAD` — the handle cannot modify the target.

```c
#include <windows.h>
#include <stdio.h>

typedef struct {
    DWORD pid;
    SIZE_T regions;
    SIZE_T committed;
    SIZE_T imageRegions;
} LayoutStats;

static DWORD InspectProcess(DWORD pid, LayoutStats *out) {
    DWORD access = PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ;
    HANDLE h = OpenProcess(access, FALSE, pid);
    if (!h) return GetLastError();   /* e.g. ERROR_ACCESS_DENIED on PPL */

    MEMORY_BASIC_INFORMATION mbi;
    unsigned char buf[256];
    SIZE_T addr = 0, got;
    ZeroMemory(out, sizeof(*out));
    out->pid = pid;

    while (VirtualQueryEx(h, (LPCVOID)addr, &mbi, sizeof(mbi))) {
        if (mbi.State == MEM_COMMIT) {
            out->committed++;
            if (mbi.Type == MEM_IMAGE) out->imageRegions++;
            /* Read-only sample of first bytes of each committed region */
            if (ReadProcessMemory(h, mbi.BaseAddress, buf, sizeof(buf), &got) && got)
                out->regions++;
        }
        addr = (SIZE_T)mbi.BaseAddress + mbi.RegionSize;
    }
    CloseHandle(h);
    return ERROR_SUCCESS;
}
```
